# v7.7 — Persistent Material & Market Circulation

12 × 140-year circulation simulations; zero hard failures.

- 36,174 persistent objects
- 114,515 transport events
- 4,809 processing transformations
- 4,351 title-changing market sales
- 954 crafted artifacts with parent-material genealogy
- 460 magical consumptions retained as terminal history
- 31,766 inheritance transfers
- 10,411 objects with multiple sale/inheritance events

Estates are explicit owners and cannot personally process/trade/craft. This surfaced as a real integration bug in the first pass and was corrected.

Value is composed from functional base, current supply/scarcity, physical condition, quantity and provenance depth—not a rarity-color price table.

Transformation preserves source identity through parent genealogy. Consumption terminates availability without deleting historical identity.

Next: persistent knowledge, specialist techniques, apprenticeships, transmission, variation and emergent craft schools.
